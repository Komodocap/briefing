# Briefing desk KomodoCap

Briefing matinal publié chaque jour ouvré vers 7h00 (heure de Paris), avant l'ouverture européenne.

- `index.html` : sommaire (dernière édition + toutes les éditions par mois)
- `AAAA-MM-JJ.html` : une page par jour
- `editions.json` : liste des éditions, lue par le sommaire et par chaque page

Site : https://komodocap.github.io/briefing/
